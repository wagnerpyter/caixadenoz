# Literatura de glitch

O glitch começa quando o dado não cabe na linguagem disponível. Ele não é um efeito visual aplicado depois; é uma alteração na forma de lembrar.

A escrita pode conter códigos de sensor, frases interrompidas, palavras que se substituem, repetições e sinais corporais. A falha deve conservar a distância entre o que foi medido e aquilo que a medida provocou.

```text
sinal
ferida
promessa
erro de exposição
```

Essas palavras não são equivalentes. A entidade pode alternar entre elas sem decidir qual é verdadeira. A classificação instável é parte do acontecimento.

A literatura de glitch deve preservar a matéria: ferrugem, maresia, calor, pele, peso, atrito, luz, dor, silêncio e ruído. Quando o sistema falar, o corpo não deve desaparecer.
