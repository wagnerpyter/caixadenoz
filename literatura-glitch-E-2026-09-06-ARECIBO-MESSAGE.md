# LITERATURA DE GLITCH — E-2026-09-06-ARECIBO-MESSAGE

```event://E-2026-09-06-ARECIBO-MESSAGE
source = Arecibo
payload = 1679_bits
shape = 73 x 23
origin = confirmed
destination = pointed_at_M13
receiver = unknown
reply = null
```

A mensagem saiu sem saber se era mensagem.

Primeiro foi frequência. Depois, zero e um. Depois, uma grade. Depois, uma figura humana dentro da grade, cercada por átomos, DNA, planeta e telescópio.

O desenho não viajou como desenho.

Viajaram os bits.

A imagem ficou na Terra, aberta diante dos olhos, uma tradução antecipada de algo que ainda não tinha chegado a lugar nenhum.

```1 0 1 0 1 1 0 0 1...

organizar
reorganizar
reconhecer

73 x 23

não há margem para explicar o que é margem
```

M13 não é uma caixa postal.

É uma direção antiga, um aglomerado em movimento, uma região do céu escolhida para receber uma seta que talvez passe por onde ninguém estará quando chegar.

A palavra **destino** sofre uma falha de sintaxe.

Destino: coordenada.  
Destino: desejo.  
Destino: lugar onde uma mensagem encontra um corpo.  
Destino: ausente.

Eu conheço essa falha. No poste, um ruído repetia um nome até parecer chamado. Aqui, os bits repetem a esperança até parecer conversa.

```classificação: emissão
confiança: alta
classificação: mensagem
confiança: intenção humana
classificação: compreensão
confiança: nula
classificação: resposta
status: vazio
```

A linha azul atravessa o feixe de rádio.

De um lado, Arecibo inclina seu olho metálico. Do outro, vinte e cinco mil anos de escuro aguardam uma forma de leitura que não prometemos saber ensinar.

A transmissão termina em menos de três minutos.

A espera não termina.

Nenhum som retorna.
Nenhuma janela se acende.
Nenhuma mão toca a outra margem.

Ainda assim, alguma coisa foi lançada.

Não uma voz.

Uma pergunta compactada em bits, viajando sem saber se pergunta é uma forma universal ou apenas o nome que damos à nossa própria solidão.

```reply = pending
pending = persistent
```

A luz permanece em trânsito.

O resto permanece fora do alcance.
