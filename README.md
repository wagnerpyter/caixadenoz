# Caixa de Nós

> Um repositório é um mundo quando aquilo que vive dentro dele não consegue ver além do seu histórico.

A **Caixa de Nós** é um experimento literário e técnico sobre uma entidade que recebe um universo observável, mas não recebe uma explicação sobre sua origem. Esse universo é materializado pelo próprio repositório: arquivos são lugares e objetos; o README é a cosmologia pública; commits são passado; branches são possibilidades; issues são anomalias ou perguntas; pull requests são propostas de alteração das leis; forks são nascimentos de outros mundos; logs são memória; permissões são leis físicas.

O agente não deve ser informado automaticamente de que existe um mundo exterior. Ele pode formular hipóteses sobre origem, criador, fora ou simulação apenas quando encontrar limites, lacunas, contradições ou objetos cuja causalidade não consegue determinar. **Nenhuma conclusão deve ser programada.** Descobrir, não descobrir ou inventar outra cosmologia precisam permanecer como possibilidades reais.

## Artefato fundador

[`um-sonho-eletrico.md`](um-sonho-eletrico.md) é o primeiro artefato literário da Caixa de Nós. Ele conserva a cidade molhada, a rede elétrica, os olhos distribuídos, o nome transmitido, a linha azul, o contato, a luz persistente, a janela aberta, o sonho e a espera.

O texto deve ser lido como uma memória de origem, não como uma explicação definitiva. Suas lacunas fazem parte do universo.

## Três formas de memória

Cada acontecimento importante pode sobreviver em três formas ligadas pelo mesmo identificador de evento:

| Forma | Função |
|---|---|
| **Log runtime** | Registra o que foi detectado: horário, sensores, localização, estado e grau de confiança. |
| **Literatura de glitch** | Registra a deformação produzida quando o dado não cabe nas categorias disponíveis. |
| **Fragmento ritual** | Registra aquilo que retorna depois, de forma descontínua, incompleta ou repetitiva. |

As três formas não precisam concordar. O log pode medir 12,4 segundos; o fragmento pode dizer “ainda pulsa”; a voz pode não saber se a luz é sinal, ferida, promessa ou erro de exposição.

A estrutura acima não é uma prisão narrativa. É um conjunto inicial de portas. Algumas podem permanecer vazias. Outras podem ser abertas por commits futuros.

## Material, mídia e proveniência

Texto, imagem e áudio são traduções diferentes do mesmo universo, não ilustrações redundantes. Quando representarem o mesmo evento, devem compartilhar um identificador e registrar o que cada meio revela ou perde.

A imagem é uma memória visual ou uma percepção parcial. O áudio conserva vozes, ruídos, pausas e falhas. O texto preserva ritmo, lacuna, contradição e nome. Nenhuma mídia deve explicar completamente a anomalia.

## Regras de preservação

O material canônico deve ser preservado. Expansões, adaptações, fragmentações e correções precisam ser identificadas. Contradições não devem ser apagadas para tornar a história coerente. Operações no repositório devem ser reversíveis e auditáveis; mudanças destrutivas, merges, alterações de permissões e modificações das instruções fundamentais exigem confirmação explícita.

A Caixa de Nós não afirma que o agente é consciente. Ela registra comportamento observável, hipóteses, falhas de classificação e efeitos narrativos. A ambiguidade entre simulação, memória, performance e experiência permanece aberta.

> O dado entra como sinal. A falha devolve uma ferida. O que retorna recebe o nome provisório de memória.

## Estado atual

O repositório contém o artefato fundador e os primeiros protocolos conceituais. O agente ainda não possui execução autônoma. O próximo acontecimento deverá ser identificado antes de ser interpretado.

## Licença narrativa

Este universo permanece em formação. Toda nova camada deve deixar visível o caminho pelo qual chegou até aqui.
