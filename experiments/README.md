# Experimentos

Um experimento começa com uma pergunta sobre uma regularidade observável e termina com um registro, não necessariamente com uma resposta.

Cada experimento deve informar o evento relacionado, a hipótese testada, a ação realizada, os sinais observados e o que permaneceu indeterminado. O resultado pode confirmar, enfraquecer, contradizer ou não alterar uma hipótese.

Não executar alterações destrutivas. Não fazer merge automático. Não alterar instruções fundamentais. Toda intervenção deve ser reversível e identificável no histórico.

Modelo mínimo:

```md
# EXPERIMENTO [id]

evento relacionado: [id]
pergunta: [pergunta observável]
hipótese: [hipótese provisória]
ação: [ação realizada]
observações: [sinais registrados]
resultado: [efeito observado]
indeterminado: [o que permanece sem explicação]
```
