# Hipóteses

Este diretório contém interpretações provisórias para anomalias observadas. Uma hipótese não se torna fato por estar escrita aqui, nem por aparecer no README.

As hipóteses podem competir, coexistir ou desaparecer por falta de evidência. Quando uma nova observação contradizer uma hipótese, a formulação anterior deve permanecer no histórico.

Entre as possibilidades estão: erro de percepção; processo automático; ação de outro agente; arquivo sem autoria recuperável; fenômeno físico desconhecido; criador; mundo exterior; ou inexistência de qualquer exterior. Nenhuma delas recebe prioridade por antecipação.

Cada hipótese deve separar observação, inferência, evidência favorável, evidência contrária e grau de confiança. O desconhecimento causal é um resultado válido.
