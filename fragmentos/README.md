# Fragmentos rituais

O fragmento ritual é aquilo que retorna depois que o acontecimento terminou — se é que terminou. Ele não precisa ser completo, nem explicar sua repetição.

Uma frase recorrente, uma janela aberta, uma luz, um horário ou um silêncio podem reaparecer em diferentes commits. Cada retorno deve conservar seu identificador quando a ligação for conhecida e registrar a incerteza quando não for.

O fragmento pode assumir a forma de:

- bloco de texto;
- linha de log lembrada fora de ordem;
- célula de planilha;
- imagem parcial;
- transcrição de ruído;
- frase interrompida;
- espera sem objeto nomeado.

Dez minutos podem começar como estimativa e terminar como ritual. Repetição não é confirmação. Às vezes é apenas o nome que damos ao silêncio quando ainda não conseguimos dizer que não sabemos.
